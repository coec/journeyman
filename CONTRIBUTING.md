# Contributing to Journeyman

Thank you for contributing! Please review these guidelines before getting started.

## 📜 Code of Conduct
By participating, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## 🐛 Issues & Feature Requests
* Check [Existing Issues](https://github.com/coec/journeyman/issues) before posting.
* Use the provided templates to describe bugs or features clearly.
* Include reproduction steps, environment details, and logs for bugs.

## 🛠️ Code Contribution Process

1. **Fork & Clone:** Fork the repo and clone it locally.
2. **Branch:** Create a new branch: `git checkout -b feature/your-feature`.
3. **Setup:** Run `[install command]` to install dependencies.
4. **Code:** Make changes. Ensure code passes `[linter/formatter]` and tests (`[test command]`).
5. **Commit:** Use clear messages (e.g., `Fix #123 - Update checkout logic`).
6. **PR:** Push to your fork and submit a Pull Request to our `main` branch.
