Connection tests

Tests each saved, enabled server independently using the stored bind account and certificate settings. Save changes before testing; directory integration does not need to be enabled yet.

Failover rules

  • Connection, TLS, timeout, or service failures advance to the next server.
  • Directory queries fail closed when every enabled server is unavailable.
  • At least two enabled LDAPS servers are required.
  • AD remains authoritative for users and Team membership.
