Outbound proxy

Optional. Route this inventory provider's HTTP/HTTPS requests through a proxy. Select a URL / API credential whose Base URL is the proxy URL and whose authentication is either None or HTTP Basic. Proxy passwords remain encrypted in the credential store and are never copied into inventory configuration.

Warning: A proxy can observe destination metadata and, for plain HTTP destinations, request content. Use a trusted proxy and keep TLS verification enabled. The proxy host must also be permitted by Journeyman's outbound allowlist.
